# Projet Modélisation Géométrique

Notre Projet se trouve dans le fichier **PMG.ipynb**, il est divisé en 3 parties:
- Calculer des splats du nuage de points
- Estimer la surface implicite
- Trouver un point sur la surface

>Pour faire des rendues avec beaucoup de points (plus de 500), il est préférable d'utiliser le fichier **PMG_HP.py** (haute performance) qui est une version sans les affichages intermediaire du fichier PMG.py .
